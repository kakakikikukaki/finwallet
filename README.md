# FinWallet

A Digital Wallet System built as a portfolio project to demonstrate backend and full-stack development skills.

## Project Overview

FinWallet is a simulated digital wallet application that allows registered users to manage their wallet balance and perform financial transactions within the FinWallet system.

## Main Features

- User registration and authentication
- JWT-based authentication
- Wallet balance and status management
- Simulated wallet top-up
- Wallet-to-wallet transfer
- Payment and expense recording
- Transaction history

## Technology Stack

| Component | Technology |
|---|---|
| Backend | Java 21, Spring Boot 4 |
| Database | PostgreSQL |
| ORM | Spring Data JPA / Hibernate |
| Security | Spring Security, JWT |
| Build Tool | Maven |
| Frontend | Angular |
| API | REST |

## Disclaimer

This project is developed for educational and portfolio purposes. All financial transactions are simulated and do not involve real money.

## Development Approach & AI Assistance

FinWallet is developed as a personal portfolio project to demonstrate backend development, software design, database management, API development, security implementation, and software testing.

AI tools, including ChatGPT, are used as development assistants to support:
- Requirements analysis and documentation.
- System design and architecture planning.
- Database and API design.
- Technical guidance and implementation suggestions.
- Code review and troubleshooting.

The project owner is responsible for reviewing, understanding, validating, and implementing the proposed solutions, as well as testing and maintaining the application.

AI-generated suggestions are not treated as automatically correct and are subject to review and validation throughout development.
